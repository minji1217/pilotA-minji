## 차이 1 — 후배 그래프는 "LS 예전 규칙 (NA 제외)"로 그렸다

후배 README 3장에 사용자 지시로 그렇게 적혀 있다.
같은 폴더 `03_가중평균AUC.csv`의 "LS 현재 코드 (NA→0)" 블록이 우리 값이다.

| 조건 | 예전 규칙 (83행·5이벤트) | 현재 코드 (418행·9이벤트) |
|---|---|---|
| A fixed | 0.8400 → 0.8550 | 0.8850 → 0.8607 |
| C bounded | 0.8163 → 0.8031 | 0.8969 → 0.8812 |
| F c=2 | 0.8679 → 0.8658 | 0.8373 → 0.8379 |

예전 규칙은 9개 이벤트 중 4개가 "전부 양성"이라 AUC가 정의되지 않아 통째로 빠지고,
남은 5개도 음성이 전부 합쳐 20행뿐이다. 우리가 NA를 0으로 되살린 이유가 이것이다.

## 차이 2 — 후배의 정답지가 구버전이다 (③ 자연+혼재)

`validation/LS_LF 데이터자료.xlsx`의 **2004 니가타현주에쓰(LS) 시트 `ls_type`**이
후배 파일에는 비어 있고, 우리가 받은 파일에는 8행이 채워져 있다.

```
15202 혼재 / 15208 자연 / 15215 자연 / 15421 자연
15441 자연 / 15442 자연 / 15445 자연 / 15446 자연
```

나머지 410행의 `ls_type`은 완전히 같다 (자연 53 · 혼재 16 · 인공 9 · 불명 20).

후배 쪽에서는 그 8행이 빈칸이라 음성이 되고, 그러면 2004 니가타 이벤트의 양성이 0이
되어 **이벤트가 가중평균에서 통째로 빠진다**(60행 손실 → 8이벤트 358행).
후배가 최신 정답지로 다시 돌려야 한다.

## 차이 3 — 불명 20행 처리 (유일한 진짜 방법론 차이)

불명 20행은 **전부 산사태가 확인된 행**이고 사면 종류만 판별 불가다.
아래는 둘 다 신버전 정답지로 다시 계산한 값이다 (3번 b10 기준).

| 규칙 | 평가 행 | prior | 사후 |
|---|---:|---:|---:|
| 불명 → 평가 제외 (우리) | 398 | **0.9023** | **0.8638** |
| 불명 → 음성(0) (후배) | 418 | 0.8883 | 0.8474 |

**제외가 맞다고 본다.** ③의 질문은 "USGS prior가 자연사면 붕괴를 설명하는가"인데,
판별 불가를 음성으로 단정하면 "인공사면이었다"고 가정하는 것이라 가설에 불리한 쪽으로
답을 미리 정해 버린다. 모르면 빼는 것이 중립이다.
다만 20행이면 4.8%이고 값이 0.014 움직이므로 **두 값을 민감도로 같이 적는다.**

## 데이터 해시에 대해

입력 파일 4개의 sha256이 모두 다르지만 **값은 같다**(π 418행 차이 0).
xlsx는 내용을 바꾸지 않고 다시 저장만 해도 바이트가 달라진다.
따라서 후배 README 7장의 "해시가 다르면 데이터가 다르다"는 맞지만 역은 성립하지 않는다.
해시가 달라도 값 대조를 해봐야 한다 — 실제로 이번에도 4개 중 실제로 내용이 다른 것은
`validation/LS_LF 데이터자료.xlsx` 하나뿐이었다.
