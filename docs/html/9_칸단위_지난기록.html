칸 단위 실험: 지난 기록 (seed 0 · 1, 고치기 전 soft 등)

최종 결과(seed 5개 평균, 고친 soft)가 나오기 전의 기록입니다. 여기의 ② · ③ · ④는 대부분 고치기 전 soft(5~10° 칸도 둘 다 낮춤) 결과입니다. 최종 결과는 칸 단위 실험 기록에 있습니다.

★칸 soft의 5~10° 칸 문제: 산사태 · 액상화 둘 다 낮아져 있었음 (10.21 발견)

칸 단위 soft는 칸의 경사 하나로 판단합니다. 10° 이상 칸은 산사태만, 5° 미만 칸은 액상화만 일어날 수 있다고 보고, 일어날 수 없는 쪽 재해의 사전확률을 1/100로 낮춥니다 (로짓에 log 0.01 = −4.6을 더함). 그런데 그 사이인 5~10° 칸은 "10° 이상"도 "5° 미만"도 아니어서 두 재해 모두 낮아졌습니다.

왜 이렇게 됐나, 시정촌 단위에서는 괜찮았나

시정촌 단위: 비율이라 문제 거의 없음

시정촌 안에 비탈·평지·중간 칸이 섞여 있어 비율의 log를 더합니다. 예: 熊本市는 비탈 20%, 평지 66%라서 산사태 log 0.20 = −1.60, 액상화 log 0.66 = −0.42. 중간 칸은 두 비율을 조금씩 줄일 뿐이고, 시정촌 전체가 중간 경사인 곳은 거의 없어 "둘 다 −4.6"은 사실상 안 생깁니다.

칸 단위: 비율이 0 아니면 1

같은 식을 칸에 그대로 옮기면 칸 하나의 비탈 비율은 (경사 ≥ 10°), 평지 비율은 (경사 < 5°)라서 0 또는 1입니다. 5~10° 칸은 두 비율이 모두 0, 1% 바닥값으로 잘려 둘 다 log 0.01 = −4.6이 됩니다. 일부러 정한 규칙이 아니라 식을 옮기다 생긴 부작용입니다.

무엇을 고쳤나, 무엇을 다시 돌리나

  • 고친 규칙 (run_cells_max.py --soft-mid): 산사태는 경사 5° 미만 칸만, 액상화는 경사 10° 이상 칸만 낮춤. 5~10° 칸은 둘 다 USGS 값 그대로. 끄기 지도(⑤)가 5~10° 칸을 둘 다 켜 두는 것과 같아짐
  • 다시 돌리는 것: soft를 쓰는 ② · ③ · ④만, seed 0 다음 seed 1 (run_cells_softmid.bat, 결과 폴더 끝 _aw_mid, 기존 결과는 그대로 둠)
  • 안 돌려도 되는 것: ⑤ 끄기 지도 + U (원래 5~10° 칸 둘 다 켬), ① baseline (soft 없음), 시정촌 단위 실험 (비율이라 영향 거의 없음)
  • 5° · 10° 기준 자체는 결과를 보기 전에 terrain_fractions.py에서 정한 값으로, 원본 LOCAL.mat에서 가져온 것이 아닙니다. 논문은 "액상화는 평지, 산사태는 비탈" 정도만 말합니다
