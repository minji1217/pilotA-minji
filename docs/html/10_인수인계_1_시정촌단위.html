DisasterNet 시정촌 단위 실험

시정촌 하나를 한 줄로 두고 DisasterNet을 돌린 실험입니다. 무엇을 하려고 했고, 어떻게 돌렸고, 어떻게 나왔는지를 순서대로 정리했습니다. 이 결과를 보고 다음 단계로 넘어간 칸(픽셀) 단위 실험은 2편에 있습니다.

0.751시정촌 단위 최고 (SOFTU_분산만)
0.854USGS 기준선 (USGS 확률을 그대로 점수로)
0.855pilotA (우리 기존 방법)
0.614DisasterNet 기본 설정 (DN)

숫자는 모두 전체 AUC (평가 시정촌 200곳), seed 0~4 다섯 번 평균입니다.

1무엇을 하려고 했나

지진이 난 뒤 시정촌마다 산사태 · 액상화가 났는지를 맞히는 문제입니다. 시정촌별 정답(났음 1 / 안 났음 0)이 있고, 모델이 낸 확률이 정답을 얼마나 잘 줄 세우는지(AUC)로 평가합니다.

비교 대상은 두 가지입니다.

  • USGS 기준선 (0.854): 미국지질조사국(USGS)이 지진 직후 내는 산사태 · 액상화 확률 지도를 시정촌 값으로 모아 그대로 점수로 쓴 것
  • pilotA (0.855): 우리가 먼저 만든 방법

질문은 하나였습니다. USGS 확률에 위성 영상(DPM)을 더해 DisasterNet으로 고치면, USGS보다 잘 맞힐 수 있나?

2DisasterNet 다시 보기

논문: Li et al., DisasterNet: Causal Bayesian Networks with Normalizing Flows for Cascading Hazards Estimation from Satellite Imagery, KDD 2023. 공식 코드: github.com/SusuXu/DisasterNet

지진이 나면 산사태 · 액상화 같은 재해가 땅을 바꾸고, 그 변화가 위성 영상에 남습니다. DisasterNet은 반대로 "땅이 이만큼 변했으니 여기서는 무엇이 일어났을 것"을 추론합니다. USGS 확률을 출발점(사전확률)으로 두고, 위성 신호를 가장 잘 설명하도록 확률을 고친 결과(사후확률)가 답입니다. 학습에 정답을 쓰지 않습니다. 정답은 채점할 때만 씁니다.

사후확률DPM까지 보고 고친 확률. 모델의 답

  • 지진마다 따로 학습 (5개 지진 = 5번), 정답은 안 씀
  • Adam, 학습률 0.01, 3000 epoch, 학습 때 시정촌마다 샘플 8개, 끝나면 샘플 256개 평균을 사후확률로 저장
  • seed 0 · 1 · 2 · 3 · 4 다섯 번

4시정촌에 맞게 바꾼 것

원 논문은 화소(위치) 하나마다 확률을 냅니다. 우리는 시정촌 하나를 한 줄로 바꿨습니다. 그래서 세 가지를 바꿨습니다.

4.1 건물붕괴(BD) 노드를 뺐다

교수님 지시로 산사태 · 액상화만 남겼습니다. 빼 보니 기본 실험 네 개 모두 전체 AUC가 올랐습니다 (DN 0.606에서 0.614, SOFT 0.677에서 0.710, DNU 0.669에서 0.675, SOFTU 0.722에서 0.738). 이후 모든 실험은 BD 없이 돌립니다.

4.2 왜 "끄기"가 문제인가

원 논문은 화소마다 일어날 수 없는 재해를 0으로 고정합니다(끄기). 비탈 화소는 액상화를, 평지 화소는 산사태를 끕니다. 그러면 "이 화소의 DPM 변화는 산사태 때문"처럼 원인이 하나로 좁혀집니다.

시정촌에서는 그대로 못 합니다. 시정촌 하나에 비탈과 평지가 섞여 있기 때문입니다. 예를 들어 熊本市는 비탈 20%, 평지 66%라 산사태를 끌 수도, 그냥 둘 수도 없습니다. 그래서 끄는 대신 아래 두 가지를 넣었습니다.

4.3 지형 정보 soft: 비율만큼 사전확률을 깎는다

산사태 사전확률에는 log(비탈 비율)을, 액상화 사전확률에는 log(평지 비율)을 로짓에 더합니다 (비율이 1%보다 작으면 1%로).

예 (熊本市)비율로짓에 더하는 값효과
산사태비탈 20%log 0.20 = −1.60산사태 사전확률이 크게 내려감
액상화평지 66%log 0.66 = −0.42조금만 내려감
비탈 100%인 곳100%log 1 = 0그대로

비율이 0에 가까울수록 끄기에 가까워집니다. 비탈 칸이 하나도 없는 시정촌은 산사태가 1/100(로짓 −4.6)로 내려가 사실상 꺼집니다.

4.4 USGS 불확실도 U: 끄기와 분산 두 가지 역할

U 끄기시정촌 안 USGS 칸의 불확실도가 전부 0 또는 999(USGS가 계산 안 한 곳)이면 그 재해를 0으로 고정. 공식 코드와 같은 기준. 실제로 꺼진 곳: 산사태 5곳, 액상화 11곳
U 분산확률을 뽑는 정규분포의 폭을 기본값 1 대신 그 시정촌 USGS 불확실도 평균으로. USGS가 불확실하다고 본 곳은 넓게, 확신하는 곳은 좁게 뽑힙니다

산사태로 꺼지는 5곳은 원래 산사태 정답이 없는 곳이라 채점에 안 들어가고, 액상화로 꺼지는 11곳은 모두 노토의 피해 없음 시정촌입니다.

6채점 방법

AUC = 피해 있는 시정촌 하나와 없는 시정촌 하나를 뽑았을 때, 피해 있는 쪽 확률이 더 높을 확률. 0.5는 동전 던지기, 1은 완벽입니다. 확률 크기는 상관없고 순서만 봅니다.

  1. 지진 × 재해마다 따로 AUC를 냅니다. 정답이 한쪽뿐이면 AUC를 못 내서 뺍니다 (산사태 후쿠시마 · 노토, 액상화 오사카)
  2. 전체 AUC = 지진별 AUC를 그 지진의 시정촌 수로 가중평균. 산사태 49곳 + 액상화 151곳 = 200곳
  3. seed 0~4 각각 AUC를 낸 뒤 평균
지진 × 재해피해 있음 / 없음USGSDNSOFTSOFTUSOFTU_분산만

값은 seed 5개 평균 AUC. 산사태는 피해 없음이 2~4곳뿐이라 짝 하나에 AUC가 크게 움직이고, 후쿠시마 액상화는 피해 없음이 1곳뿐이라 거의 의미가 없습니다. 채점 코드: disasternet/compare_latest.py

8무엇을 알게 됐나

  1. 지형 정보(soft)가 산사태를 크게 올립니다. 산사태 AUC가 DN 0.512에서 SOFT 0.777로 오릅니다. 비탈이 적은 시정촌의 산사태 확률을 깎는 것이 잘 통합니다.
  2. USGS 불확실도의 효과는 대부분 분산에서 옵니다. DNU_분산만(0.681)이 DNU 전체(0.675)와 비슷하고, 끄기만(0.638)은 효과가 작습니다. 꺼지는 시정촌이 적기 때문입니다 (산사태 5곳은 채점 대상이 아니고, 액상화 11곳은 채점 대상의 7%).
  3. soft 위에서도 같습니다. SOFT 0.710에 분산을 더하면 0.751 (+0.041), 끄기를 더하면 0.722. 다만 soft가 없을 때(DN 0.614에서 DNU_분산만 0.681, +0.067)보다 오르는 폭은 줄어듭니다.
  4. 가장 좋은 SOFTU_분산만도 0.751로, USGS 기준선 0.854와 pilotA 0.855보다 낮습니다. 산사태는 USGS보다 높지만(0.792 대 0.729), 액상화가 크게 낮습니다(0.738 대 0.895).
  5. seed마다 흔들림이 큽니다. 같은 설정도 seed에 따라 전체 AUC가 0.04~0.12 달라지고, 시정촌 확률 값이 지진 전체로 통째로 오르내립니다. 특히 지형 정보가 없으면 산사태 순서가 seed마다 거의 무관합니다 (DN의 seed끼리 순위 상관 0.08).
그래서 칸(픽셀) 단위로 넘어갔습니다

시정촌 단위로는 원 논문처럼 "일어날 수 없는 재해 끄기"를 제대로 할 수 없고, 시정촌 평균 DPM에서는 좁은 곳(액상화가 나는 강가 · 매립지)의 신호가 묻힙니다. 교수님 지시로 250 m 칸마다 학습하고, 시정촌 값은 칸 사후확률의 최댓값으로 내는 실험을 했습니다. 결과는 0.808로 시정촌 최고 0.751보다 높았습니다. 자세한 내용은 2편: 칸(픽셀) 단위 실험.

9다시 돌리기

raw/와 outputs/는 용량 때문에 저장소에 올리지 않았습니다. 선배에게 폴더를 따로 받아야 합니다. 저장소: minji1217/pilotA-minji, 브랜치 claude/dazzling-babbage-8c6yd4.

필요한 파일

  • raw/DisasterNet_입력_v5.xlsx (입력 통합표), raw/terrain_fractions.csv (지형 비율), raw/muni_usgs_pixel.csv (시정촌별 USGS 불확실도)

학습 (저장소 맨 위 폴더에서)

O=outputs/disasternet; T=raw/terrain_fractions.csv; U="--usgs-muni raw/muni_usgs_pixel.csv --no-bd --jobs 5"
python -m disasternet.run_input_v5 --no-bd --out-dir $O/nobd_DN   --jobs 5
python -m disasternet.run_input_v5 --no-bd --terrain $T --out-dir $O/nobd_SOFT --jobs 5
python -m disasternet.run_muni_unc $U                         --out-dir $O/px_DNU
python -m disasternet.run_muni_unc $U --terrain $T            --out-dir $O/px_SOFTU
python -m disasternet.run_muni_unc $U --unc off               --out-dir $O/px_DNU_off
python -m disasternet.run_muni_unc $U --unc var               --out-dir $O/px_DNU_var
python -m disasternet.run_muni_unc $U --unc off --terrain $T  --out-dir $O/px_SOFTU_off
python -m disasternet.run_muni_unc $U --unc var --terrain $T  --out-dir $O/px_SOFTU_var

실험 하나(seed 5개)에 몇 분 걸립니다. 결과는 폴더마다 predictions_seed0.csv ~ seed4.csv (열: seed, event_idx, muni_code, p_ls, p_lq).

채점

10주의할 점

  • 저장소에 예전 시도 코드가 많이 남아 있습니다 (cellmix, hard, orig_port, input_v5_* 폴더 등). 이 문서에 나온 파일과 폴더만 보면 됩니다.
  • pilotA 숫자는 0.855(원래 설정)를 씁니다. 채점 스크립트에 다른 pilotA 결과 폴더를 넣으면 0.834처럼 다르게 나올 수 있습니다.
  • U 끄기 기준은 불확실도 0 · 999만입니다 (공식 코드와 같음). USGS 확률이 0인 것은 기준에 넣지 않습니다.
  • 시정촌 USGS 값에는 물 칸도 들어 있습니다. 사전확률 표가 원래 그렇게 만들어져 있어서 불확실도도 같은 규칙으로 맞췄습니다.
  • 산사태 표본이 작습니다. 피해 없음이 구마모토 3곳, 오사카 2곳, 훗카이도 4곳뿐이라 산사태 AUC는 크게 흔들립니다.
  • seed 하나만 보고 결론 내지 마세요. 반드시 5개 평균으로 비교합니다.
