③자연+혼재 재평가 교수님 지시

USGS 산사태 사전모형이 설명하는 것은 자연사면의 붕괴인데, 정답의 양성에 성토·옹벽·법면 같은 인공사면 붕괴가 섞여 있다. 모형이 원리적으로 맞힐 수 없는 사건까지 양성으로 세고 있는 셈이다. 학습을 다시 하지 않는다 — 2·3번 브랜치에서 평가 옵션만 켜고 결과 이름으로 구분한다(4번=2번, 5번=3번).

④면적 항 A~J A~F 지시 G~I 추가 J 요청

z = a·log p̄ + b + c·(log k − m), k = 시정촌 면적 ÷ 격자 한 칸 넓이. USGS 값 p̄는 “발생 확률”이 아니라 “격자 한 칸 중 덮이는 면적 비율”이다. 넓은 시정촌일수록 한 곳이라도 무너질 확률이 높다. 칸이 독립이면 λ = p̄ × k, P(하나라도) = 1 − exp(−λ)이고, 포화를 피해 순위가 같은 log λ = log p̄ + log k를 쓴다. 그래서 a=1, b=0, c=1 이 유도식 그대로다.

2. G · H · I · J 는 왜 그 값으로 정했나

A~F를 돌리고 나서 관찰된 것 — 같은 c = 1 인데 두 hazard의 눈금이 정반대로 어긋난다.

c = 0.5 (E)c = 1.0 (A)c = 2.0 (F)
산사태 LS 편향−0.494 무너짐+0.006 거의 완벽+0.146
액상화 LQ 편향−0.103+0.256 크게 과대+0.501

→ 두 hazard가 서로 다른 c를 원한다. LS의 유도값 1은 건드리지 말고, LQ만 내려 보자. 물리적으로도 그럴 만하다 — c=1은 “칸끼리 독립”에서 나온 값인데, 액상화 감수성은 충적층·지질을 따라 공간적으로 강하게 상관되므로 1 − ∏(1−pᵢ)가 과대추정한다. 유효 칸 수가 명목 k보다 작다는 뜻이고, 그것이 c_LQ < 1로 나타난다.

Gc_LQ = 0.5 고정 — E에서 이미 확인된 반대쪽 값. LQ 편향이 −0.103으로 부호가 뒤집히는 지점을 그대로 가져왔다.

Hc_LQ = 0.75 고정 — 관찰값 두 개(0.5 → −0.103, 1.0 → +0.256)로 편향 0 교차점을 선형 추정하면 0.643. 0.25 간격 격자에서 그 위쪽 점을 잡았다.

Ic_LQ 만 학습 — 사람이 고르지 말고 우도가 고르게 둔다. c ∈ [0, 2]에서 학습해 0.434로 수렴했다.

Jb 만 학습 — c를 건드리면 순위까지 같이 움직인다. b는 z에 더해지는 상수라 hazard 안에서 순위를 전혀 바꾸지 않고 확률 높이만 옮긴다. 눈금을 고치는 올바른 손잡이는 c가 아니라 b라는 가설이다.

3. ⑤ c 스윕 — 무엇을, 왜

무엇 — AreaPrior(mode="grid")로 c_LS와 c_LQ를 직접 지정하고 a=1, b=0은 고정해서 prior에서 학습하는 값이 0개인 상태로 c만 바꿔 돌린다. 거친 격자 c ∈ {0.5, 0.75, 1.0, 1.25, 1.5, 1.75, 2.0} 7×7 = 49점 + 최적점 주변 미세 격자. 브랜치는 followup3-area-sweep이다.

왜 — ④에서 c를 0.5 / 1 / 2 세 점으로만 봤기 때문이다. 그 세 점만으로는 “유도값 1이 정말 최적인지”, “LQ의 최적이 어디인지”를 말할 수 없다. 편향이 0을 지나는 c를 직접 찾아 유도값이 맞는지 데이터로 검증하는 것이 목적이다. c가 prior를 바꾸면 posterior도 바뀌므로 c마다 회귀 44개를 새로 적합한다(한 점 14초).

검증 — 격자점 (1.0, 1.0)이 조건 A와 완전히 일치한다. 스윕 배선이 맞다는 확인이다.

부수 발견 — 두 hazard의 c는 서로 간섭하지 않는다. 한쪽 c를 0.5~2.0으로 바꿔도 다른 쪽 편향은 0.004 안에서만 움직인다. c_LS와 c_LQ를 따로 골라도 된다.

5. 결론과 한계

1. 유도식 c = 1 이 산사태에서 정확히 맞는다. 편향 0 교차 c_LS ≈ 0.99, MSE 최소도 1.0. A fixed의 편향 +0.006 / MSE 0.0998로 기저확률 0.1344를 크게 밑돈다. “칸끼리 독립” 가정이 산사태에서는 성립한다.

2. 액상화는 c를 0.62로 낮춰야 한다. 감수성이 충적층을 따라 공간적으로 상관돼 유효 칸 수가 명목보다 적다. H(c_LQ=0.75)가 LQ MSE 0.1868로 1위다.

3. b를 학습하면 오히려 나빠진다. B·C·J가 편향 −0.27, MSE 0.21~0.26으로 최악이다. prior의 자유도를 늘리는 것이 답이 아니다. J의 가설(“b가 올바른 손잡이”)은 이 평가 집합에서는 성립하지 않았다.

4. 피해 데이터의 기여는 판정할 수 없다. A·G·H·I는 보탠양 +0.011~+0.015로 양수지만 부트스트랩 95% 구간이 [−0.041, +0.073]으로 0을 포함한다. LS 평가에 음성이 20행뿐이기 때문이다 — 9개 이벤트 중 4개는 음성이 0개라 AUC를 잴 수조차 없어 빠진다. 편향과 MSE가 더 믿을 만한 지표다.

남은 일 — ① A~J를 자연+혼재 정답(418행)으로도 재채점 중이다. 음성이 20 → 341행이 되어 AUC가 안정된다. ② NA 304행을 근거별로 갈라 「조사 대상이었으나 기록 없음」과 「조사 여부 불명」을 나누면 평가 집합을 넓힐 수 있다. ③ c_LS=1.0, c_LQ≈0.62를 정식 조건으로 브랜치화. ④ LQ 최대집계 + 면적 항 결합(λ = p̄·k 유도가 평균집계를 전제하므로 이론 정리가 먼저).
