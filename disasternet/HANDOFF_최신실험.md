## 1. 한 줄 요약

**USGS 사전확률 + 위성 변화지도(DPM)를 DisasterNet(KDD 2023)으로 결합해 시정촌별 산사태·액상화 확률을 냈더니,
가장 좋은 설정(④)이 전체 AUC 0.715로 USGS 사전확률만 쓴 기준선(0.854)과 pilotA(0.855)보다 낮았다.**
원인은 "시정촌 단위"라는 데 있다고 보고, 다음 단계는 화소(칸) 단위 사후확률을 시정촌 최댓값으로 모으는 것이다 (7장).

## 2. 배경: DisasterNet이 뭔가

- 논문: Li et al., *DisasterNet: Causal Bayesian Networks with Normalizing Flows for Cascading Hazards Estimation from Satellite Imagery*, KDD 2023
- 공식 코드: <https://github.com/SusuXu/DisasterNet>

**아이디어**: 지진이 나면 산사태(LS)·액상화(LQ, 논문에선 LF)·건물붕괴(BD)가 생기고, 이것들이 위성 영상에 "땅이 변했다"는 신호(DPM)를 남긴다.
DPM을 보고 거꾸로 "어디서 무엇이 일어났는지"를 추론한다. **정답 라벨을 학습에 쓰지 않는다 (비지도).**

```
USGS 산사태 확률 ─▶ [산사태 LS] ─┐
                                 ├─▶ [건물붕괴 BD] ─┐
USGS 액상화 확률 ─▶ [액상화 LQ] ─┘                   ├─▶ 관측 DPM
                    PGV ──────────────┘             │
                   LS, LQ ──────────────────────────┘
```

- 각 노드의 사전확률(prior): USGS가 낸 확률을 출발점으로 쓴다
- 사후확률(posterior): DPM까지 보고 나서 고쳐진 확률. 이것이 모델의 답
- 관측식: `log(DPM + 2) ≈ w0 + w_LS·q_LS + w_LQ·q_LQ + w_BD·q_BD` (q = 사후확률)
  → "DPM이 크면 무언가 일어났을 것"이라는 연결고리

**원 논문은 화소 단위**다 (DPM 화소 하나 = 한 위치 = 사후확률 하나). 평가도 화소별 정답 지도로 했다
(산사태 AUC: 아이티 0.984, 푸에르토리코 0.952, 홋카이도 0.951 / Table 2).
공식 코드에는 평가 코드가 없고, 화소별 사후확률 지도를 `.mat`로 저장하고 끝난다.

**우리는 시정촌 단위**로 바꿔서 돌렸다. 시정촌 하나 = 한 줄.

| # | 이름 | 출력 폴더 (`outputs/disasternet/…`) | 지형 비율 soft | USGS 불확실도 |
|---|---|---|---|---|
| ① | DN | `input_v5_lqmax` | ✗ | ✗ |
| ② | SOFT | `input_v5_terrain_lqmax` | ○ | ✗ |
| ③ | DNU | `input_v5_muni_unc_lqmax` | ✗ | ○ |
| ④ | SOFTU | `input_v5_muni_unc_soft_lqmax` | ○ | ○ |

### 4-1. 왜 "끄기"가 필요한가

원 논문은 화소마다 **불가능한 재해를 0으로 고정(끄기)** 한다.
- 비탈 화소 → 액상화 불가 → 액상화 0
- 평지 화소 → 산사태 불가 → 산사태 0
- 건물 없는 화소 → 건물붕괴 0
- USGS가 계산하지 않은 화소 → 0

끈 노드는 사후확률이 0으로 고정되고, DPM을 설명하는 데에도 빠진다. 그래서 "이 화소의 DPM 변화는 산사태 때문이다"처럼 원인이 하나로 좁혀진다.

**시정촌에서는 그대로 못 한다.** 시정촌 하나에 비탈과 평지가 섞여 있기 때문이다.
264곳 중 **179곳은 비탈과 평지가 둘 다 10% 이상**이고, 비탈이 1% 이하라 산사태를 끌 수 있는 곳은 23곳, 평지가 1% 이하인 곳은 3곳뿐이다.
(화소는 위치가 하나라 경사 값도 하나 → 0% 아니면 100%라서 끄기가 자연스럽다.)

그래서 끄는 대신 두 가지를 시도했다.

### 4-2. soft (② ④) — 지형 비율로 사전확률을 깎는다

- `frac_LS` = 비탈 비율 (250 m 칸 평균 경사 ≥ 10°), `frac_LQ` = 평지 비율 (경사 < 5°), `frac_BD` = 건물용지 비율
- 자료: 국토수치정보 (행정구역 N03, 토지이용 L03-b-21, 경사 G04-d-11), 계산 코드 `disasternet/terrain_fractions.py`
- 사전확률 로짓에 `log(비율)`을 더한다 (비율이 1% 미만이면 1%로)

예) 비탈이 10%인 시정촌 → 산사태 로짓에 log(0.1) = −2.3 → 사전확률이 크게 내려감.
비탈이 100%면 log(1) = 0 → 그대로. 비율이 0에 가까울수록 "끄기"에 가까워진다.

코드: `disasternet/model.py`의 `log_p_z()` 안 `log_frac`

### 4-3. USGS 불확실도 (③ ④) — USGS가 계산 안 한 곳을 끈다

USGS 이벤트 페이지의 ground-failure 제품에는 확률 지도와 함께 **불확실도 지도**가 있다
(산사태 `jessee_2017_std` / `jessee_2018_beta_sigma`, 액상화 `zhu_2017_general_std` / `_beta_sigma`).
원 논문 코드도 이 지도를 쓴다.

하는 일 두 가지:
1. **끄기**: 시정촌 안의 250 m 칸 중 USGS가 계산한 칸(확률·불확실도가 0이나 999가 아닌 칸)이 **하나도 없으면** 그 노드를 0으로 고정
   → 실제로 꺼진 곳: 산사태 9곳, 액상화 11곳
2. **r⁰ 분산**: 사후분포 출발점 r⁰ ~ N(μ, 분산)의 분산을, 켜진 칸들의 불확실도 평균으로 고정 (안 쓰면 1)

추가로 ③ ④는 건물붕괴 r⁰ 분산을 공식 코드처럼 학습하고 [1, 5]로 묶는다 (`bd_var_learn=True`). 실제로는 거의 1에 머물렀다.

코드: `disasternet/run_muni_unc.py`, `disasternet/usgs_cells.py` (칸에 USGS 값 붙이기)

### 4-4. 학습 (넷 다 같음)

- **지진마다 따로** 학습한다 (논문과 같음). 정답은 쓰지 않는다.
- 시정촌마다 사후분포 출발점 μ에 자기만의 보정값(offset, `mu_local`)이 있고, μ는 ±6 안으로 부드럽게 묶는다 (`6·tanh(·/6)`)
- planar flow 4층, 학습 때 시정촌마다 샘플 8개, triplet loss(λ=1, margin=1), KL β warm-up
- Adam, lr 0.01, 3000 epoch, seed 5개 (0~4)
- 끝나면 샘플 256개 평균을 사후확률로 저장 → `predictions_seed{N}.csv` (열: event_idx, muni_code, p_ls, p_lq, p_bd)

코드: `disasternet/model.py`의 `fit_disasternet()` → `_fit_group()`

## 5. 평가 방법 (AUC)

코드: `disasternet/compare_latest.py` (덱의 숫자는 전부 이 스크립트 결과)

1. **행**: pilotA 결과에도 있는 시정촌만 쓴다 (공통 263곳). 같은 행, 같은 정답으로 비교하기 위해서다.
2. **지진마다 따로** AUC를 낸다. 정답이 한쪽뿐인 지진은 AUC를 정의할 수 없어서 뺀다.
3. seed 5개 각각 AUC → 평균
4. **전체 = Σ(지진 AUC × 그 지진의 시정촌 수) / Σ 시정촌 수**
5. ALL = 산사태 지진들과 액상화 지진들을 같은 방식으로 한꺼번에 가중평균 (200곳)

AUC 뜻: 정답 1인 시정촌 하나와 0인 시정촌 하나를 무작위로 뽑았을 때 1인 쪽에 더 높은 확률을 줄 확률. 0.5 = 동전 던지기, 1 = 완벽.

**실제로 채점된 지진**

| 재해 | 지진 (양성 / 음성) | 빠진 지진 |
|---|---|---|
| 산사태 (49곳) | 구마모토 26/3 · 오사카 5/2 · 홋카이도 9/4 | 후쿠시마 · 노토 (음성 0) |
| 액상화 (151곳) | 구마모토 18/22 · 홋카이도 17/23 · 후쿠시마 6/1 · 노토 33/31 | 오사카 (양성 0) |

주의: 산사태는 표본이 작다 (음성 3곳, 2곳인 지진도 있음). 후쿠시마 액상화는 음성이 1곳뿐이라 그 지진의 AUC는 거의 의미가 없다.

> `run_input_v5.py`가 자체로 내는 `auc_overall.csv`는 가중치가 다르다 (양성×음성 쌍 수 가중). 덱·문서 숫자는 `compare_latest.py` 기준.

### pilotA와 비교할 때 알아 둘 것

| | pilotA A2 | DisasterNet ①~④ |
|---|---|---|
| 관측 자료 | 피해 통계 (전괴·반괴 등) | DPM (위성) |
| 학습에 정답 라벨 | 산사태 라벨 사용 | 사용 안 함 |
| 학습 지진 | 평가 지진을 **빼고** 나머지 8개 (분리 실험) | 평가 지진 1개만 |
| 평가 | 같은 263곳, 같은 정답, 같은 AUC 규칙 | 같음 |

- pilotA는 정답으로 학습하므로 평가 지진을 빼야 한다 (안 빼면 정답 누출).
- DisasterNet은 정답을 안 쓰므로 같은 지진으로 학습·평가해도 누출이 아니다.
- pilotA 숫자 출처: pilotA 원본 저장소 `followup4-lq-J-labels` 브랜치, `--holdout-event`로 지진마다 돌린 `outputs/holdout_detail_*` 파일. A2 = `lqnolab`, A1 = `lqlab`, 사후는 `p_*_alpha_fit` 열, prior는 `z_cov_kappa`(산사태)·`z_kappa_lq`(액상화) 열.

## 7. 왜 시정촌 단위에서 안 되나 → 다음 단계

**원인 (지금까지의 판단)**
1. **끌 수가 없다.** 한 시정촌에 비탈·평지가 섞여 있어서, 원 논문의 핵심인 "불가능한 재해 끄기"가 거의 안 된다 (4-1).
2. **DPM이 사후확률에 거의 반영되지 않는다.** 관측식 가중치(w_LS, w_LQ)가 학습 중 0 쪽으로 줄어든다.
   그러면 "DPM이 크다 → 재해가 있었다"는 연결이 약해지고, 결과가 사전확률 + 잡음에 가까워진다.
3. **자유도가 너무 크다.** 시정촌마다 보정값(offset)이 있어서, 지진 하나(시정촌 수십 곳)에 비해 학습할 값이 많다.
   seed마다 다른 답에 도착하는 이유로 본다.

**교수님 지시 (다음 실험)**
- BD는 버린다 (산사태·액상화만)
- 켜고 끄기는 일단 생각하지 않는다 (soft 값은 알 수 있지만 무시해도 됨)
- 학습은 하던 대로
- **추론: 시정촌 안 화소(칸)들의 사후확률 중 최댓값을 그 시정촌의 사후확률로 본다** (USGS 액상화를 '최대'로 집계한 것과 같은 느낌). 이 값으로 AUC를 구한다.

**필요한 자료**
- 화소 DPM. DPM을 만들 때 40 m 화소 DPM이 있었지만(3장), 저장소에는 시정촌 집계표만 있다.
- 250 m 칸별 DPM 표(이벤트, mesh250, DPM 평균, 화소 수)를 만들면 `local_250m_byevent_usgs.csv`와 mesh250으로 바로 붙일 수 있다.
  이 파일에는 칸별 USGS 확률(`us_ls`, `us_lq`)이 이미 있다.

**칸 DPM이 없을 때의 임시안**: 지금처럼 시정촌 단위로 학습한 모델을 칸마다 적용한다.
칸마다 바뀌는 건 그 칸의 USGS 확률, DPM은 시정촌 값을 그대로 쓴다. 그 칸 사후확률들의 최댓값으로 시정촌 값을 낸다.

## 8. 아직 모르는 것

- **USGS 불확실도 효과의 정체.** 액상화 +0.07 중 +0.015만 직접 효과(꺼진 곳 = 정답 0)다. 나머지가 아래 중 어느 쪽인지 따로 돌려 보지 않았다.
  - (가) 액상화가 불가능한 11곳이 학습에서 빠져서 나머지 시정촌의 관측식이 더 잘 맞춰짐
  - (나) r⁰ 분산이 거의 0이라 (산사태 평균 0.005, 액상화 0.014 — 기본값 1과 비교) 샘플링 잡음이 줄어듦
  - 확인 방법: 끄기만 켜고 분산은 1로 둔 실험
- 불확실도가 "USGS가 확신하는 곳은 사후가 prior 근처에 머물게 한다"는 설명은 **틀렸다.** 코드상 분산은 r⁰ 폭에만 들어가고, μ는 시정촌마다 자유롭게 학습되므로 prior 쪽으로 당겨지지 않는다.

## 9. 용어표

| 용어 | 뜻 |
|---|---|
| prior (사전확률) | 위성 자료를 보기 전의 확률. 여기선 USGS 확률 |
| posterior (사후확률) | DPM까지 보고 고친 확률. 모델의 답 |
| DPM | Damage Proxy Map. 지진 전후 위성 영상의 상관도 차이. 땅이 변하면 큼 |
| 끄기 (off) | 그 시정촌·화소에서 불가능한 재해를 사후확률 0으로 고정하고 DPM 설명에서도 뺌 |
| soft | 끄는 대신 log(가능한 땅 비율)만큼 사전확률을 깎는 것 |
| USGS 불확실도 | USGS 확률 지도와 같이 나오는 불확실도 지도. 0·999 = 계산 안 함 |
| r⁰, μ | 사후분포를 만드는 출발점 정규분포 N(μ, 분산). flow를 거쳐 sigmoid로 확률이 됨 |
| planar flow | 출발 분포를 여러 번 휘어서 더 복잡한 분포로 만드는 층 (논문의 normalizing flow) |
| triplet loss | 산사태 사후는 산사태 prior에, 액상화 사후는 액상화 prior에 더 가깝게 묶는 벌점 |
| β warm-up | 학습 초반엔 KL 항을 약하게 했다가 점점 1로 올리는 것 |
| offset (`mu_local`) | 시정촌마다 μ에 더하는 자유 보정값 |
| 분리 실험 (holdout) | pilotA에서 평가 지진을 빼고 나머지로 학습하는 것 |
| A1 / A2 | pilotA 분리 실험. A1 = 액상화 라벨도 학습에 씀, A2 = 산사태 라벨만 |
